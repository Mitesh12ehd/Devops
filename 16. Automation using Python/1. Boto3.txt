Resource vs client:
    - in boto3 client is much low level API 
    - resource: provide resource objects to access attributes and perform actions   


Python vs Terraform:
    - TF manage state of infra
    - TF is idemptent(get the same result every time)
    - in TF we can delete resource easily

    - Python execute script regardless of condition of infra state  
    - Need to write code for delete or manually delete
