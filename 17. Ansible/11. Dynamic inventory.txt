How to run playbook on specific server?
    - We can apply filters in inventory files
    - to check available filter on documentation of ec2 plugin

    ex.
        ---
        plugin: aws_ec2
        regions: 
            - ap-south-1
        filters:
            tag:Name: dev*
            instance-state-name: running

How can we group server?
    - for ex. we want to create group of production servers and group of dev servers

    - we can group by tag   
        ---
        plugin: aws_ec2
        regions: 
        - ap-south-1
        keyed_groups:
        - key: tags
          prefix: "tag"

    - it create groups with tag name 
        ex. tag_Name_dev_server
            tag_Name_prod_server

    - we can use other attribute than tag to group the server
        ex. instance type
    - we can check output of ansible-inventory -i inventory_aws_ec2.yaml --list Command 
      and we can group based on any attribute of that 
      
    
    - we can use this groups in hosts attribute of play
