1. Create sealed-secret.yaml
   Create secret.yaml

1. Install Sealed Secrets Controller
    kubectl apply -f https://github.com/bitnami-labs/sealed-secrets/releases/latest/download/controller.yaml

2. verify pod 
    kubectl get pods -n kube-system
    
    expected:
        sealed-secrets-controller-76b686947b-x2fbf   1/1     Running   0        65s

3. Install kubeseal CLI
    - kubeseal --version

4. Create secret file (temporary):
    
    apiVersion: v1
    kind: Secret
    metadata:
        name: ledger-secret
        namespace: payments
    type: Opaque
    stringData:
        STRIPE_API_KEY: sk_live_9f3a2b7c1e4d8REDACTED 
        DB_PASSWORD: P@ssw0rd123

5. Convert secret into sealed secret
    kubeseal \
    --format yaml \
    < secret.yaml \
    > sealed-secret.yaml

6. Create secret:
    kubectl apply -f sealed-secret.yaml

    - The controller detects the new SealedSecret.
      It automatically creates a standard Kubernetes Secret.

7. verify secret
    kubectl get secret -n payments
    kubectl describe secret ledger-secret -n payments
