Configmap and secret as kubernetes volume:
    - in application, we need property file to store some configuration
    - some information are sensitive

Example: Create mosquitto and use our own configuration

    1. Create Configmap
        mosquitto/config-file.yaml
    
    2. Create secret
        mosquitto/secret-file.yaml

    3. Create mosquitto deployment
        mosquitto/mosquitto.yaml

        - Need to mount configmap and secret volume inside container so that application access it.

        - mountPath:
            - we can find it by going inside pod/container
                kubectl exec -it mosquitto-79bdb75d48-n6zfh  -- bin/sh
                ls mosquitto/config

        - we can mark volume mounted as read only,
          so that application can't modify it

    4. Verify configuration inside container

        - go into pod
            kubectl exec -it mosquitto-7b47d5788f-m2vt4  -- bin/sh

        - verify config file content
            cat mosquitto/config/mosquitto.conf

        - verify secret file content
            cat mosquitto/secret/secret.file
