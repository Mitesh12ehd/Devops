Deploy using helm charts:
    - we have similar configuration for all microservices
    - can we use helm charts?

    1. Initialize helm chart
        - helm create microservice
        - it initialize chart structure

        - Chart.yaml contains metadata about chart
        - charts/ : it contains any chart dependencies that this chart have
                    - empty as we don't have any dependencies as of now
        - .helmignore:
            - files that you don't want to include in helm chart
        - template:
            - where actual k8s configuration template file created

    2. Define variable in deployment and service file

        way1: {{ .Values.appName }}, {{ .Values.appReplicas }}  # best practice
        way2: {{ .Values.app.name }}, {{ .Values.app.replicas }}    # hierarchical

        - To define multiple variable, use range

    3. values.yaml
        - define common values in values.yaml file

    4. custom value files:
        - pass value of each microservice through custom value file

    5. How to validate template and its values
        helm template -f email-service-values.yaml microservice

        or 

        helm lint -f email-service-values.yaml microservice

        or 

        helm install --dry-run -f [custom_value_fila path] [chart name or path]
    
    6. How to deploy?

        Way1:
            - install for each microservice
            - helm install -f [custom_value_file_path] [release_name] [chart_name]

        Way2: 
            - create shell script
            - execute

Helmfile:
    - declarative way for deploying helm charts

    1. Create helm file
        helmfile.yaml

    2. Install helmfile tool
        (separate installation on each platform )

    3. Execute helmfile
        helmfile sync

    3. Uninstall all release
        helmfile destroy
