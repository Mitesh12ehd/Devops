Credential:
    - Credential can be added and configured from
        Manage jenkins > Credential

Create new credential:
    - Click on Add credential

    Scope of credential:
        - We can choose global or system scope of credential

        1. System:
            - credential are only available for jenkins server
            - credential not for jenkins job
            - it may require for jenkins administrative task

        2. Global:
            - Accessible everywhere

    Type of credential:

        1. Username with password:
            - most commonly used
            - ID : used to refer credential

        2. Other types are
            Github app, 
            ssh username with private key,
            Secret file
            Secret text
            Certificate

Multi-branch pipeline credential scope:
    - other than global and system, multi-branch pipeline have it's own Scope

    Create credential in Multi-branch pipeline credential scope:
        - Multi-branch pipeline > Credential > Stores scoped to my-multi-branch-pipeline > Create


Use credential from GUI

    Method 1: Define and use
    pipeline{
        agent any
        environment{
            // credentials is method, github-credential is ID that we have given on Jenkins GUI
            SERVER_CREDENTIAL  = credentials('github-credential')
        }
        stages{
            stage("build"){
                steps{
                    echo "Building application"
                    sh 'echo "Building with $SERVER_CREDENTIAL_USR $SERVER_CREDENTIAL_PSW"'
                }
            }
        }
    }  

    Method 2: use directly inside steps
    steps{
        withCredentials([
            usernamePassword(credentials: 'github-credential', usernameVariable: USR, passwordVariable: PWD)
        ]){
            // We can use USR and PWD here
            sh 'echo "Building with ${USR} ${PWD}"'
        }
    }
