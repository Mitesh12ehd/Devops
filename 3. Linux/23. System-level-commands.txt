System level commands:

    - uname:
        - to know platform of our os 
        - for ubuntu is linux

    - uptime:
        - give time from when machine is up
        - give number of user

    - who:
        - shows user logged in and their activity 
        - ex. when used logged in etc.

    - whoami:
        - shows current logged in username

    - which:    
        - to find out location of program or application 

        ex.
            which bash
            which python3

    - id:
        - shows details of current user's 
            - user and user id
            - group and group id
            - user is part of which groups 

    - sudo:
        - super user do
        - it execute command with administrator permissions

        - sudo is group
        - any user which is part of sudo group can execute command with sudo level permissions

        - id command shows current user is part of sudo group or not

    - shutdown, reboot:
        - to perform its tasks
        - we can also schedule by giving time parameter
